# Surplus Power

Home Assistant custom integration for charging a portable power station from
surplus generation. The integration controls only the power station's charging
input. Ventilation power is a read-only measurement and is never controlled.

See the [user guide](docs/user.md) for installation, configuration, controller
behavior, and troubleshooting. See the [developer guide](docs/developer.md) for
architecture, testing, commit hooks, and deployment.
